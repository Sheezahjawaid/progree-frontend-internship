# Task 3: Asynchronous REST API Weather Portal Application

A single-page Vanilla JavaScript application that fetches real-time weather data from the **OpenWeatherMap REST API** using the Fetch API and `async/await`[cite: 9].

## Features
- Asynchronous weather retrieval using `fetch` and `async/await` with `try / catch` error handling[cite: 9].
- Dedicated loading spinner and clear error messages for invalid cities, unauthorized keys, or network failures[cite: 9].
- Dynamic DOM rendering for temperature, feels-like temperature, humidity, wind speed, pressure, and weather condition icon.
